# E-Commerce Application Code

Application-only repository for the e-commerce microservices project.

Services:
- frontend: Next.js customer application
- user-service: registration, login, JWT and profile
- product-service: products and categories
- cart-service: customer cart
- order-service: orders and delivery status
- payment-service: demo payment processing
- notification-service: AWS SNS SMS and Amazon SES email notifications

AI/Bedrock chat is intentionally excluded from this phase and will be added later as a feature branch.
Docker files are intentionally excluded from this phase.
